# 🐱 Professor Whiskers: Interactive Coding Tutor

An animated purple cat that explains coding concepts (variables, loops, functions, lists, Big-O) and gives a computer science course overview.

🔗 **Live demo:** https://hafsakhalil826-lab.github.io/code-cat-tutor/

## Features
- Animated cat drawn in SVG
- Typing-effect speech bubble with code snippets
- Lo-fi background music (Web Audio API)
- Optional voice narration (Web Speech API)

## Built with
HTML, CSS, JavaScript, SVG, Web Audio API, Web Speech API

*Built with the help of AI tools.*
