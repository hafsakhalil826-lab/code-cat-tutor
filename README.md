# Professor Whiskers: Interactive Coding Tutor

An animated purple cat that explains coding concepts (variables, loops,
functions, lists, Big-O) and gives a computer science course overview.

**Live demo:** https://hafsakhalil826-lab.github.io/code-cat-tutor/

## Features
- Animated cat (blinking, tail wag, talking mouth) drawn in SVG
- Typing-effect speech bubble with code snippets
- Lo-fi background music generated with the Web Audio API
- Optional voice narration with the Web Speech API

## Built with
HTML, CSS, JavaScript, SVG, Web Audio API, Web Speech API

Built with the help of AI tools.
